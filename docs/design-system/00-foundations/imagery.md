# Imagery & illustration

## Purpose

Visual style for photography, product shots, and illustration that matches KeyNest warmth and trust.

## Photography (Brand Book)

- Real people using real lockers, keys, and phones — not stock office scenes
- Natural light, candid moments, everyday city and street settings
- Product shots show the green KeyNest locker clearly and in context
- Place colour logo on sage or white; reversed white lockup on ink / dark photography

## Illustration

| Attribute | Spec |
| --------- | ---- |
| Style | Flat, soft geometry; rounded forms echoing the bird mark |
| Line | 1.5–2px equivalent; no harsh outlines |
| Palette | Action green, Sage, Cream, Ink, Yellow highlight accents |
| Complexity | Minimal scenes; one focal idea |
| Metaphor | Access, keys, paths, calm security — never padlocks-as-fear |

## Logo (do not redesign)

- Clear space ≥ height of bird icon on every side
- Min digital: icon 24px tall; full lockup 90px wide
- Min print: lockup 25mm wide
- Don’t stretch, recolour bird outside palette, rotate, or place on busy/low-contrast photos

## When to use

Marketing heroes, empty states (simple illustration), onboarding, help articles.

## When not to use

- Don’t use generic cyber/lock clipart
- Don’t put dense photo backgrounds behind dense UI

## Best practices

Prefer sage washes behind photos; cream for testimonial/callout cards with portraits.

## Engineering notes

Serve WebP/AVIF; reserve aspect ratios to avoid layout shift. Logo SVGs from brand kit only.
