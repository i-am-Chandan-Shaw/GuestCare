# Opacity, borders, sizing & z-index

## Opacity

| Token | Value | Use |
| ----- | ----- | --- |
| opacity-disabled | 0.5 | Disabled controls |
| opacity-muted | 0.64 | De-emphasised icons |
| opacity-overlay | 0.45 | Scrim (via overlay color) |
| opacity-hover | 0.08 | Ink wash on hover (if needed) |
| opacity-pressed | 0.12 | Press wash |

## Border widths

| Token | Value | Use |
| ----- | ----- | --- |
| border-0 | 0 | Reset |
| border-1 | 1px | Default cards/inputs |
| border-2 | 2px | Focus emphasis (rare), active tab |

## Sizing scale (control heights)

| Token | px | Use |
| ----- | -- | --- |
| size-control-sm | 32 | Compact controls |
| size-control-md | 40 | Default buttons |
| size-control-lg | 48 | Large / touch |
| size-control-xl | 52 | Floating label inputs |
| size-icon-button | 32 / 40 | Icon buttons |
| size-touch-min | 44 | Min touch target |

## Z-index

| Token | Value | Use |
| ----- | ----- | --- |
| z-base | 0 | Default |
| z-dropdown | 20 | Menus |
| z-sticky | 30 | Sticky headers |
| z-overlay | 40 | Scrim |
| z-modal | 50 | Dialog |
| z-popover | 60 | Popover above modal tools |
| z-toast | 70 | Toasts |
| z-tooltip | 80 | Tooltips |
| z-max | 9999 | Dev only |
